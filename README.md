# FLEUR Telegram Flower Shop

Demo flower storefront and Telegram bot for Dnipro. Orders are test-only; real payments, delivery and persistence are not enabled.

Deployment: Vercel, with `BOT_TOKEN`, `ADMIN_CHAT_ID`, `TELEGRAM_WEBHOOK_SECRET`, and `PUBLIC_APP_URL` configured in project environment variables. Rotate the bot token shared in conversation before use.
